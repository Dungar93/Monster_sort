\section{The Game or Puzzle}

\subsection{Overview and objective}
\textit{Dual-Realm Discrete Adventures} is an integrated mathematical gaming system comprising two interconnected titles: \textbf{Monster Sort: The Sorting Kingdom} and \textbf{The Robot Maze Challenge}. Together, they bridge two foundational pillars of discrete mathematics: set theory with Boolean logic, and graph theory with algorithmic state-space search.

\begin{itemize}
  \item \textbf{Realm 1: Monster Sort (The Taxonomic Realm).} In the kingdom of Sortoria, players encounter a diverse population of procedurally generated monsters exhibiting seven distinct morphological dimensions (color, horns, wings, eyes, body shape, skin pattern, and size). Players assume the role of the ``Grand Sorter'', tasked with placing creatures into overlapping planar Venn regions governed by unary characteristic predicates. The objective is to achieve a mathematically sound partition of the monster universe by evaluating set membership, Boolean intersections ($\cap$), unions ($\cup$), set differences ($\setminus$), complements ($A^c$), and De Morgan's identities with zero constraint violations.
  \item \textbf{Realm 2: The Robot Maze Challenge (The Algorithmic Realm).} Players guide an autonomous robot named ``Robo'' through a progression of 12 handcrafted maze environments toward a target treasure chest. The game demonstrates that a spatial grid is fundamentally an unweighted graph $G = (V, E)$, that valid routes correspond to graph paths, and that the Breadth-First Search (BFS) algorithm computes a provably optimal shortest path in $O(|V| + |E|)$ time. Players can compete directly against the algorithm in ``Robot Race'', investigate reachable components, and conduct experiments in an interactive ``Math Detective'' laboratory.
  \item \textbf{The Unifying Gateway: The Discrete Math Sorting Hat.} Before entering the realms, players undertake an interactive 5-question discrete mathematics personality assessment. Based on their cognitive problem-solving style, the Sorting Hat profiles them as a \textit{Set-Theoretic Classifier} (directed primarily to Monster Sort), a \textit{Graph-Algorithmic Pathfinder} (directed to Robot Maze), or a \textit{Dual Master of Discrete Realms} (unrestricted access to both), illustrating how static set classification and dynamic graph exploration form dual facets of discrete problem-solving.
\end{itemize}

The central canvas renders $k \in \{1, 2, 3\}$ intersecting closed Jordan curves defining sets $A_1, \dots, A_k$, surrounded by a bounded region representing the universal complement $\left(\bigcup_{i=1}^k A_i\right)^c$.

  \end{itemize}
\end{itemize}

\subsection{Rules and how to play}

\subsubsection*{Rules of Realm 1: Monster Sort}
\begin{enumerate}
  \item \textbf{Predicate Truth Conditions:} For $k$ active set curves $A_1, \dots, A_k$, each set represents a unary Boolean predicate $P_i : U \to \{0, 1\}$. Creature $M_j \in A_i \iff P_i(M_j) = 1$.
  \item \textbf{Disjoint Minterm Placement:} The $k$ curves partition the plane into $2^k$ mutually exclusive minterm regions. A placement of monster $M_j$ into geometric region $\mathcal{R}$ is legally valid if and only if:
  $$\forall i \in \{1, \dots, k\}, \quad \mathcal{R} \subseteq A_i \iff P_i(M_j) = 1$$
  \item \textbf{Universal Complement Requirement:} Monsters satisfying no predicates ($\forall i, P_i(M_j) = 0$) must be placed in the outer realm $\mathcal{R}_0 = \bigcap_{i=1}^k A_i^c$. Placing them inside any circle triggers an immediate constraint violation error.
  \item \textbf{Compound Logic Gates:} Advanced chambers feature compound set expressions (e.g., $(R \cup H) \setminus W$). A creature is valid in this chamber if and only if its characteristic vector satisfies $(P_R \lor P_H) \land \neg P_W = 1$.
  \item \textbf{Winning Condition:} The level completes when all $|U|$ creatures are placed with zero errors. Score is computed as $S = \max(0, 1000 - 10 \cdot t - 50 \cdot m)$ for elapsed time $t$ and invalid attempts $m$.
\end{enumerate}

\subsubsection*{Rules of Realm 2: The Robot Maze Challenge}
\begin{enumerate}
  \item \textbf{Graph Transitions:} Robo can transition from vertex $u = (r, c)$ to adjacent vertex $v = (r', c')$ if and only if $|r - r'| + |c - c'| = 1$ (orthogonal movement: North, South, East, West). Diagonal moves are forbidden.
  \item \textbf{Wall Invariance:} Cells marked as walls cannot be entered. Attempting to move into a wall or the boundary does not advance Robo, generates an audio collision feedback, and does not increment the move count.
  \item \textbf{Path Construction:} A legal run consists of a sequence of vertices $\pi = \langle v_0, v_1, \dots, v_L \rangle$ such that $v_0 = s$, $v_L = d$, and $(v_i, v_{i+1}) \in E$ for all $0 \le i < L$.
  \item \textbf{Shortest Path Optimality and Hints:} Each level computes the exact geodesic distance $\delta(s, d)$ using BFS. Players earn 3 stars by reaching the destination, using a path of minimum length $L = \delta(s, d)$, and completing the level without automated BFS hints.
  \item \textbf{Robot Race Mode:} In round A, the human player navigates the maze. In round B, an automated BFS agent traverses an optimal path. The interface superimposes both routes, contrasting human heuristic detours against the algorithmic shortest path.
\end{enumerate}

\section{The Mathematical Question}

Two dual mathematical problems govern the project:

\begin{quote}
\textbf{Question 1 (Set-Theoretic Partition in Monster Sort).} Given a finite universe $U$ and $k$ independent unary Boolean predicates $P_1, \dots, P_k$ defining subsets $A_i = \{x \in U \mid P_i(x) = 1\}$:
Do the $2^k$ fundamental minterm intersections $\bigcap_{i=1}^k A_i^{(b_i)}$ (where $b_i \in \{0, 1\}$) form an exact mathematical partition of $U$, guaranteeing that every creature possesses a unique, deterministic placement computed in $O(k)$ time?

\textbf{Question 2 (Geodesic Optimality on Grid Graphs in Robot Maze).} Given a finite unweighted planar graph $G = (V, E)$ derived from an $R \times C$ grid with wall obstacles:
Does the Breadth-First Search (BFS) algorithm using a First-In-First-Out (FIFO) queue always compute the exact geodesic shortest distance $\delta(s, d)$ in $O(|V| + |E|)$ operations, and does every predecessor backtrace yield a path of minimal length?
\end{quote}

\textbf{Connection to discrete mathematics and unified duality.}
\begin{itemize}
  \item \textbf{Set Partitions and Characteristic Functions:} For any subset $A \subseteq U$, its characteristic function $\chi_A : U \to \{0, 1\}$ establishes an algebraic isomorphism between the Boolean algebra $(\mathcal{P}(U), \cup, \cap, {}^c)$ and the bit-vector algebra $(\{0, 1\}^k, \lor, \land, \neg)$. The $2^k$ minterm regions correspond to the atoms of this Boolean algebra.
  \item \textbf{Graph Theory and State-Space Search:} An $R \times C$ maze without walls is a 2D mesh graph with $|V| = RC$ and $|E| = 2RC - R - C$. By the Handshake Lemma, $\sum_{v \in V} \operatorname{deg}(v) = 2|E|$, where interior cells have degree 4, edge cells degree 3, and corners degree 2.
  \item \textbf{The Duality Connection:} During graph traversal, the vertex set $V$ is partitioned at any step into three mutually disjoint subsets: the \textit{Visited} set, the \textit{Frontier Queue} set, and the \textit{Unexplored} set ($V = \text{Visited} \cup Q \cup \text{Unvisited}$). Thus, graph traversal dynamically maintains a 3-block set partition of the state space.
\end{itemize}

\subsection{Patterns and discoveries}
\begin{enumerate}
  \item \textbf{Exponential Partition Scaling ($2^k$):} In Monster Sort, every added predicate doubles the number of fundamental regions ($2^1 = 2, 2^2 = 4, 2^3 = 8$). Standard circular Venn diagrams cannot partition the plane into all $2^k$ connected regions for $k \ge 4$ without non-convex geometries (Venn's Theorem).
  \item \textbf{Layered BFS Wavefronts ($L_d$):} In Robot Maze, BFS expands in concentric ``ripples'' where layer $L_d = \{v \in V \mid \delta(s, v) = d\}$. All vertices in layer $L_d$ are processed before any in $L_{d+1}$, guaranteeing that the first time the destination is enqueued, its shortest distance is known.
  \item \textbf{Unit Cost Requirement:} In our experimentation with variable terrain (the ``mud'' experiment), an edge with cost $c > 1$ caused plain BFS to fail to find the cheapest path, illustrating why unweighted edges are essential for BFS optimality (and motivating Dijkstra's algorithm for weighted graphs).
\end{enumerate}

\section{Our Strategy, Conjecture, or Mathematical Claim}

\subsection{Precise statements}

\textbf{Theorem 1 (Venn Partition Theorem for Characteristic Predicates).}
Let $U$ be a finite universe and $P_1, \dots, P_k$ be $k$ Boolean predicates defining sets $A_i = \{x \in U \mid P_i(x) = 1\}$. For each index vector $\vec{b} = (b_1, \dots, b_k) \in \{0, 1\}^k$, define the minterm:
\begin{equation}
M_{\vec{b}} = \bigcap_{i=1}^k A_i^{(b_i)} \quad \text{where} \quad A_i^{(1)} = A_i, \quad A_i^{(0)} = A_i^c
\end{equation}
Then:
\begin{enumerate}[label=(\roman*)]
  \item The collection $\{M_{\vec{b}} \mid \vec{b} \in \{0, 1\}^k\}$ forms an exact partition of $U$: they are pairwise disjoint ($M_{\vec{b}} \cap M_{\vec{c}} = \emptyset$ for $\vec{b} \neq \vec{c}$) and their union is $U$ ($\bigcup_{\vec{b}} M_{\vec{b}} = U$).
  \item Every $x \in U$ belongs to exactly one minterm $M_{\vec{b}(x)}$ with index $\vec{b}(x) = (P_1(x), \dots, P_k(x))$.
\end{enumerate}

\textbf{Theorem 2 (BFS Geodesic Optimality on Unweighted Graphs).}
Let $G = (V, E)$ be a finite, connected, unweighted graph where every edge $e \in E$ has unit weight $w(e) = 1$. Let $s \in V$ be the source vertex. Then Breadth-First Search initialized at $s$ computes the exact shortest path distance $\delta(s, v)$ for every reachable $v \in V$. Furthermore, when applied to a target $d \in V$, the predecessor tree backtrace $\pi^* = \langle s, \dots, d \rangle$ attains the absolute minimum path length $|\pi^*| = \delta(s, d)$.

\subsection{Strategy and intuition}
\begin{itemize}
  \item \textbf{Characteristic Vector Sorting Strategy (CVSS) for Monster Sort:} For any creature $x$, evaluate the $k$-bit indicator tuple $\vec{b}(x) = (P_1(x), \dots, P_k(x))$ and compute integer $\operatorname{id}(x) = \sum_{i=1}^k b_i(x) 2^{k-i}$. Deposit $x$ into region $\operatorname{id}(x)$ directly in $O(k)$ time, bypassing search.
  \item \textbf{FIFO Layer-Expansion Strategy for Robot Maze:} Maintain a queue $Q$ initialized with $s$, and a distance map $d[s] = 0$. For current vertex $u = \operatorname{dequeue}(Q)$, examine orthogonal neighbors $v \in \operatorname{Adj}(u)$. If $v \notin \text{Visited}$ and $v \notin V_{\text{obs}}$, assign $d[v] = d[u] + 1$, set $\operatorname{parent}[v] = u$, and enqueue $v$. Because edges have uniform cost 1, the queue preserves the invariant that vertices are examined in non-decreasing order of distance.
\end{itemize}

\section{Proof or Counterexample}

\subsection*{Route A: Proof of the claims}

\begin{proof}[Proof of Theorem 1 (Venn Partition)]
\textbf{Pairwise Disjointness:} Let $\vec{b}, \vec{c} \in \{0, 1\}^k$ with $\vec{b} \neq \vec{c}$. There exists coordinate $j$ such that $b_j \neq c_j$. Without loss of generality, let $b_j = 1$ and $c_j = 0$. Then $M_{\vec{b}} \subseteq A_j^{(1)} = A_j$ and $M_{\vec{c}} \subseteq A_j^{(0)} = A_j^c$.
Thus, $M_{\vec{b}} \cap M_{\vec{c}} \subseteq A_j \cap A_j^c = \emptyset$. Since no element can belong to both a set and its complement, $M_{\vec{b}} \cap M_{\vec{c}} = \emptyset$.

\textbf{Exhaustive Covering:} Trivially, $\bigcup_{\vec{b}} M_{\vec{b}} \subseteq U$. Conversely, take any $x \in U$. By the Law of Excluded Middle, for each $i \in \{1, \dots, k\}$, either $x \in A_i$ (set $b_i^* = 1$) or $x \in A_i^c$ (set $b_i^* = 0$). This defines a unique vector $\vec{b}^*(x) \in \{0, 1\}^k$. By construction, $x \in A_i^{(b_i^*)}$ for all $i$, so $x \in \bigcap_{i=1}^k A_i^{(b_i^*)} = M_{\vec{b}^*(x)} \subseteq \bigcup_{\vec{b}} M_{\vec{b}}$. Thus $U \subseteq \bigcup_{\vec{b}} M_{\vec{b}}$, establishing $\bigcup_{\vec{b}} M_{\vec{b}} = U$.

\textbf{Uniqueness:} Existence is given by $\vec{b}^*(x)$; uniqueness follows because if $x \in M_{\vec{c}}$ for $\vec{c} \neq \vec{b}^*(x)$, then $x \in M_{\vec{b}^*(x)} \cap M_{\vec{c}} = \emptyset$, a contradiction.
\end{proof}

\begin{proof}[Proof of Theorem 2 (BFS Geodesic Optimality)]
Let $\delta(s, v)$ denote the true shortest distance (minimum edge count) from $s$ to $v$ in $G$. Define distance layers $L_d = \{v \in V \mid \delta(s, v) = d\}$ for $d \ge 0$, where $L_0 = \{s\}$.

\textbf{Induction Hypothesis:} For all $d \ge 0$, BFS discovers and dequeues every vertex in layer $L_d$ before dequeuing any vertex in layer $L_{d+1}$, and assigns recorded distance $d[v] = d = \delta(s, v)$ for every $v \in L_d$.

\textbf{Base Case ($d=0$):} Initially, $Q = \langle s \rangle$ with $d[s] = 0 = \delta(s, s)$. $s$ is dequeued first. The base case holds.

\textbf{Inductive Step:} Assume the hypothesis holds for layers $0, 1, \dots, d$.
Let $w \in L_{d+1}$ be an arbitrary vertex at distance $d+1$. By definition of shortest paths, there exists some vertex $v \in L_d$ such that $(v, w) \in E$, and $w \notin L_{\le d}$.
Because $w \notin L_{\le d}$, $w$ cannot have been discovered prior to processing layer $L_d$.
By the inductive hypothesis, all vertices of $L_d$ are dequeued in order. When neighbor $v \in L_d$ is dequeued, $w$ is undiscovered. The algorithm sets $d[w] = d[v] + 1 = d + 1 = \delta(s, w)$, records $\operatorname{parent}[w] = v$, and enqueues $w$.
Because $Q$ operates as a FIFO queue, all vertices discovered while processing $L_d$ are enqueued after existing vertices of $L_d$ and before any vertex discovered during $L_{d+1}$.
Therefore, all vertices in $L_{d+1}$ are enqueued behind $L_d$, and dequeued strictly before any vertex in $L_{d+2}$.

Following parent pointers backwards from $d$ generates path $\pi^* = \langle v_0 = s, v_1, \dots, v_k = d \rangle$ where each step satisfies $d[v_i] = d[v_{i-1}] + 1$. Thus, the total path length is exactly $d[d] = \delta(s, d)$, proving that no shorter path exists.
\end{proof}

\textbf{Conclusion of the proofs.}
Both mathematical claims are unconditionally proved: Monster Sort guarantees a complete and unique minterm partition, while Robot Maze guarantees that BFS computes the exact geodesic shortest path on unweighted grid graphs.

\subsection*{Final mathematical finding}
The two projects demonstrate the dual nature of discrete problem spaces: \textit{Monster Sort} solves the \textit{static taxonomic partition problem} via Boolean algebra and set theory, while \textit{Robot Maze} solves the \textit{dynamic state-space pathfinding problem} via graph theory and BFS. Both systems guarantee mathematically optimal, deterministic solutions.

\section{Interaction with School Students and Feedback}

\textbf{Introduction and guided play.}
We structured a 45-minute interactive outreach workshop for middle school students (ages 11--14), connecting the two games through the Sorting Hat:
\begin{enumerate}
  \item \textbf{Phase 1: The Sorting Hat Gateway (5 mins):} Students complete the 5-question personality assessment on tablets, discovering whether their thinking aligns with taxonomic classification or spatial graph navigation.
  \item \textbf{Phase 2: Monster Sort Challenge (20 mins):} Students explore 2-set and 3-set Venn puzzles.
  \begin{itemize}
    \item \textit{Guiding Question 1:} ``Where should a monster go if it has NEITHER horns NOR wings?'' (Encourages discovering the outer universal canvas $\mathcal{R}_0$).
    \item \textit{Guiding Question 2:} ``How many rooms are created when we cross 2 circles? What about 3 circles? Can you spot the pattern of doubling ($2, 4, 8$)?''
  \end{itemize}
  \item \textbf{Phase 3: Robot Maze Challenge (20 mins):} Students guide Robo through mazes and compete in ``Robot Race''.
  \begin{itemize}
    \item \textit{Guiding Question 3:} ``If a path turns around a wall, why did the robot not choose the open side corridor?'' (Encourages counting moves to discover geodesic distance).
    \item \textit{Guiding Question 4:} ``How is the computer checking squares like ripples spreading in a pond?'' (Visualizes BFS concentric distance layers $L_d$).
  \end{itemize}
\end{enumerate}

\textbf{Mathematics after playing.}
At the conclusion of play, facilitators lead a synthesis discussion:
\begin{itemize}
  \item \textbf{Translating Set Logic:} Connect visual Venn regions to formal operations: $\cap$ (AND), $\cup$ (OR), $\setminus$ (WITHOUT), and $A^c$ (NOT). Explain De Morgan's Law using monster traits: ``Not (Red or Horned) is equal to Not Red AND Not Horned.''
  \item \textbf{Connecting Mazes to Graphs:} Show students the ``Maze $\leftrightarrow$ Graph'' toggle in Robot Maze. Explain that tiles are vertices $V$, open connections are edges $E$, and the BFS queue explores every layer of distance $d$ before moving to $d+1$.
\end{itemize}

\textbf{Feedback and refinements.}
Key feedback gathered from student trials directly informed our design:
\begin{itemize}
  \item \textbf{Monster Sort Canvas Boundary:} Students originally tried to drop non-matching monsters on circle edges. We introduced a golden-framed ``Universal Canvas ($\mathcal{U}$)'' with an explicit ``Wild Woods'' complement label, resolving placement ambiguity.
  \item \textbf{Robot Maze Visual Hints:} When stuck, students previously resorted to random backtracking. We introduced progressive 3-stage hints (directional arrow $\to$ glowing next cell $\to$ shortest-path breadcrumb trace), all computed dynamically by BFS from Robo's current coordinate.
  \item \textbf{Audio Reinforcement:} We integrated procedural Web Audio feedback (chords for correct set placements, gentle clicks for steps, fanfare for BFS optimal completions), which students reported made the mathematical discoveries feel like an authentic adventure.
\end{itemize}
